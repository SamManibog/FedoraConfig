# My Fedora Linux Configuration

## Installation

Ensure git is installed then run the following command:
'''bash
git clone https://github.com/SamManibog/FedoraConfig ~/FedoraConfig
cd ~/FedoraConfig
python setup.py
'''

## File Structure

setup.py is the installation script for this configuration.

setup.py will copy files from ./configFiles into the home directory.
